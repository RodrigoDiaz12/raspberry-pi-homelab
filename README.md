# Raspberry Pi 5 IT Homelab

## Overview

This repository documents my journey building and managing a hands-on IT homelab using a Raspberry Pi 5, Windows 11 PC, and managed networking equipment.

The goal of this project is to develop practical skills in IT support, Linux system administration, networking, cybersecurity, and troubleshooting while creating real-world projects that demonstrate my technical abilities.

I will document each project with command outputs, screenshots, configurations, troubleshooting steps, and lessons learned.

## Hardware & Environment

| Component | Equipment |
|---|---|
| Server | Raspberry Pi 5 |
| Operating System | Raspberry Pi OS Lite (64-bit) |
| Linux Base | Debian 13 (Trixie) |
| Architecture | ARM64 |
| Main Computer | Windows 11 PC |
| Network Switch | TP-Link Omada ES208G |
| Storage | 128GB microSD |
| Cooling | Official Raspberry Pi 5 Case with fan and heatsink |

## Projects & Progress

### 1. Linux System Administration

**Status: In Progress**

- Installed and configured Raspberry Pi OS Lite.
- Configured hostname and administrator account.
- Enabled SSH for remote administration.
- Updated system packages using APT.
- Identified Linux distribution, kernel version, and system architecture.
- Created a standard Linux user account.
- Practiced user identification and group management.
- Verified administrative privileges using sudo.
- Tested the principle of least privilege.

### 2. Networking

**Status: In Progress**

- Configured Windows Internet Connection Sharing.
- Established SSH connectivity between Windows and Raspberry Pi.
- Troubleshot DHCP and IP address assignment.
- Configured a temporary static IP connection.
- Tested connectivity between devices.
- Verified internet connectivity and DNS resolution.

### 3. Windows Administration

**Status: In Progress**
